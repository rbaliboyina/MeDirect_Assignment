Info:-
Framework developed using Playwright with Typescript. 
Framework designed with Page Object Model
Framework developed such a way that we can automate API and UI. 
Fraemwork developed such a way that we can run tests in different envs. 

Pre-Requisites:-
1. Nodejs should be installed in the system

Setup:-
1. Either download or clone the project from provided github url
2. Go to the root directory of the project
3. All dependencies will get download by executing below command
   npm install
4. Execute below command for running Web tests
   npm run uatwebtest
5. Execute below command for running API positive tests (200 status code scenarios)
   npm run uatapipositive
6. Execute below command for running all API tests (including positive and negative)
   npm run uatapitest
7. After running the command, html report will get open automatically
8. In case, want to open the report with command, please execute below command
   npm run show-report
